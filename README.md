# رِواء | REWA — موقع فندق فاخر (مشروع جامعي)

موقع ويب عربي كامل باتجاه RTL لهوية فندق خيالي اسمه **رِواء | REWA** في الرياض، مبني بـ HTML وCSS وJavaScript فقط، من دون أي مكتبات خارجية. الخط الوحيد المستخدم هو **Cairo** من Google Fonts، والصور العشر هي صور المشروع نفسها داخل مجلد `images/`.

> **تنبيه المحاكاة:** هذا الموقع مشروع جامعي لمادة «التصميم الجرافيكي لواجهات الويب». الفندق خيالي، والحجز والدفع محاكاة بالكامل. لا يتم خصم أي مبلغ، ولا إرسال بريد إلكتروني، ولا حفظ بيانات بطاقة. جميع البيانات المدخلة تبقى داخل المتصفح وتُفقد عند إغلاق الصفحة.

---

## بيان الهوية قبل الكود

1. **الشخصية:** ضيافة عربية معاصرة، هادئة وفاخرة بلا صخب بصري.
2. **اللوحة:** أخضر صنوبري عميق، ذهبي مطفي، بيج دافئ، ولون واحد فقط للنداء الأساسي (تراكوتا).
3. **الشعار:** نجمة خاتم ثمانية الأضلاع بروح هندسية عربية، مع كلمة «رِواء» و«REWA».
4. **الطباعة:** Cairo بأربعة أحجام فقط، وارتفاع سطر 1.7 لنصوص القراءة.
5. **المزاج:** فراغ مدروس، صور موحّدة الدرجة اللونية، وحركة هادئة لا تتجاوز 300ms.

### تشغيل المشروع

افتح `index.html` مباشرة في المتصفح، أو شغّل خادماً محلياً بسيطاً من مجلد المشروع:

```bash
# إن كان لديك Python
python -m http.server 8000
# ثم افتح
http://localhost:8000/index.html
```

لا يحتاج المشروع إلى تثبيت أو بناء أو أدوات إضافية.

### الوصول إلى الحجز في نقرتين

- من الصفحة الرئيسية: زر «احجز إقامتك» في الواجهة أو البحث السريع ← الحجز.

### الطباعة

أربعة أحجام Cairo فقط:

```css
--fs-sm: 0.8125rem;   /* 13px */
--fs-body: 1.0625rem; /* 17px */
--fs-md: clamp(1.25rem, 1.05rem + 0.75vw, 1.75rem);
--fs-xl: clamp(2.125rem, 1.3rem + 3.6vw, 4.25rem);
```

كل نصوص القراءة بارتفاع سطر `1.7`.

### المسافات والشكل والحركة

- شبكة 12 عموداً داخل حاوية واحدة `max-width: 1200px` مع `margin-inline: auto` وحشوة أفقية `clamp(20px, 5vw, 64px)`، وهي نفسها في القائمة والهيرو وبطاقة التوفر وكل الأقسام والتذييل.
- مسافات بمضاعفات 8px: `8, 16, 24, 32, 40, 48, 56, 64, 80, 96, 120`.
- أنصاف أقطار موحدة: `4px / 8px / 14px / 999px`.
- ثلاث ظلال فقط، وحركة `220–280ms` مع احترام `prefers-reduced-motion`.
- زخرفة واحدة متكررة: نجمة خاتم ثمانية الأضلاع، مستخدمة في الشعار والخلفيات بنسبة خفيفة.

### الصور

- الصور العشر فقط، بأسماء ثابتة من `images/`، ومن دون أي رابط صورة خارجي.
- لكل صورة `width` و`height` و`alt` وصفي، و`object-fit: cover`.
- خلفية بديلة `--img-bg` لكل حاوية صورة قبل التحميل.
- تحميل كسول لكل ما هو أسفل الطية، مع «إيقاظ» الصور عند فتح خطوة أو تبويب مخفي حتى لا تبقى غير محمّلة.
- تدرّج لوني موحّد `--grade` فوق الصور لضمان وحدة بصرية وقراءة النص فوقها.

## التفاعل في `script.js`

- **الوضع الداكن:** يحفظ الاختيار في `localStorage`، ويحترم تفضيل النظام أول مرة.
- **قائمة الجوال:** فتح/إغلاق، طبقة تعتيم، إغلاق بـ Escape، حبس التركيز داخل القائمة، وإعادة التركيز إلى الزر.
- **البحث السريع:** تحقق من التواريخ، حد أقصى ٢١ ليلة، حفظ الاختيار في `sessionStorage` ثم الانتقال إلى الحجز.
- **فلاتر الغرف:** النوع والسعر والسعة، عدّاد نتائج، حالة فارغة مع زر إعادة تعيين.
- **المقارنة:** اختيار حتى ٣ غرف، تعطيل ما بعد الحد، جدول يُبنى ديناميكياً بـ DOM، إزالة غرفة من الجدول، وإغلاق/تفريغ.
- **التبويبات:** `role="tablist"` و`role="tab"` و`role="tabpanel"`، أسهم يمين/يسار وHome/End، وروابط `#overview` / `#pool` / `#restaurant` / `#spa`.
- **الحجز:** تحقق فوري لكل حقل، تعطيل الغرف التي لا تتسع للضيوف، حساب `السعر × الليالي + 15% ضريبة`، ملخص لاصق يتحدث لحظياً، محاكاة دفع مع حالة تحميل، ثم شاشة نجاح ورقم حجز تجريبي وطباعة.
- **التحقق:** بريد إلكتروني، جوال سعودي (`05...` أو `+9665...`)، بطاقة ١٦ رقماً بخوارزمية Luhn، انتهاء `MM/YY` مستقبلي، CVV من ٣–٤ أرقام، وموافقة على السياسة.
- **بيانات الدفع التجريبية:** `4242 4242 4242 4242` مع أي تاريخ مستقبلي وأي CVV من ٣–٤ أرقام.

## إمكانية الوصول (Accessibility)

- رابط «تخطّى إلى المحتوى» في كل صفحة.
- HTML دلالي: `header` و`nav` و`main` و`section` و`footer` و`address`.
- تسميات صريحة لكل حقل، وربط الأخطاء بـ `aria-describedby`، و`aria-invalid` عند الخطأ.
- حالات الأزرار: hover / focus-visible / active / disabled / loading / success.
- حلقة تركيز واضحة، وأهداف لمس بارتفاع 44px على الأقل (بما فيها الشعار والفتات).
- الحالة لا تُنقل باللون وحده: أيقونة + نص بجانب كل نجاح/خطأ/تحذير.
- جداول المقارنة تحتوي `caption` و`scope`، والصورة الزخرفية في الملخص لها `alt` فارغ عند عدم اختيار غرفة.
- نتائج Lighthouse المحلية للصفحات الخمس: **Accessibility 100** و**Best Practices 100** و**SEO 100** (بدون إخفاقات).

## اختبارات تمت

- فتح الصفحات الخمس على خادم محلي: لا أخطاء JavaScript في الـ Console.
- التحقق من وجود كل أيقونة `<use href="#...">` داخل sprite الصفحة نفسها.
- فحص كل روابط الصفحات والمراسي الداخلية (لا روابط ميتة).
- تجربة الفلاتر: «السعة 5+» تعطي حالة فارغة، وزر إعادة التعيين يعيد الغرف الثلاث.
- تجربة المقارنة: غرفتان ← جدول ١٣ صفاً، وزر «إزالة» يحدّث الحالة.
- تجربة التبويبات: النقر، الأسهم، Home/End، وروابط `#spa` المباشرة.
- تجربة الحجز: تواريخ خاطئة، سعة زائدة، غرفة غير مختارة، بيانات ناقصة، بطاقة خاطئة (Luhn)، ثم نجاح برقم حجز وملخص نهائي.
- تجربة الوضع الداكن وقائمة الجوال وEscape وإعادة التركيز.
- فحص التجاوب داخل إطار بعرض 375px: لا تمرير أفقي، والأزرار والأهداف اللمسية مناسبة.
- تشغيل Lighthouse على الصفحات الخمس: Accessibility 100، Best Practices 100، SEO 100.

## ملاحظات أخيرة

- المشروع لا يستخدم أي API حقيقي، ولا خادم دفع، ولا تخزيناً خارج المتصفح.
- `sessionStorage` يُستخدم فقط لتذكّر تاريخ البحث داخل نفس الجلسة، و`localStorage` للوضع الداكن.
- بيانات البطاقة تُستخدم في المتصفح للتحقق الشكلي فقط، ولا تُرسل إلى أي جهة.
- في نسخة إنتاج حقيقية يجب استبدال المحاكاة بخادم دفع آمن، وإدارة حجوزات، وسياسة خصوصية فعلية.
